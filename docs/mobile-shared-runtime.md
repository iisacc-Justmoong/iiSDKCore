# 모바일 및 웹 공유 런타임 계약

앱이 명시적으로 `IISDKCORE_DYNAMIC_MOBILE=ON`을 선택하면 iOS의 Core와
Observation은 각각 동적 프레임워크로 빌드되어 앱이 내장할 수 있어야 한다.
WebAssembly에서는 Emscripten 사이드 모듈로 빌드할 수 있어야 한다. 이 선택은
기존 앱별 정적 플러그인 카탈로그와 별개이며 두 옵션을 동시에 사용할 수 없다.
기본 독립 Core 빌드는 기존의 iOS·웹 정적 구성을 유지한다.

이 계약은 파일 형식·링커 구성에 대한 것이다. iOS 기기 배포에는 앱의 서명과
프로비저닝이 별도로 필요하며 웹 사이드 모듈의 로드 시점과 호스트 실행 조건은
소비자가 관리한다. 테스트는 대상 형식과 연결을 검사하며 앱을 실행하지 않는다.
